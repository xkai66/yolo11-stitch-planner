《缝合计划 v0.1》摘要

先形成可解释的实验矩阵，再让脚本自动生成 YAML。

evidence first

三条主路线

A1：AFPN-P345 + RCSOSA 轻量版，观察最佳 Neck 和注意力能否叠加。

A2：ELA-HSFPN + TADDH，复现现有 retry 正收益，作为强组合对照。

A3：UIB/ExtraDW + AFPN-P2345（必要时切换 P345）+ base Detect，验证轻量骨干与浅层融合。

验收顺序

接口 dry-run → 单模块 5 轮 → 同轮次超过 base 才进组合 → 2–4 组消融 → 1–3 个组合做 100 轮 → 独立 test 最终评估。

新模块没有本地结果时只叫“候选”，不能写成“已验证创新”。
